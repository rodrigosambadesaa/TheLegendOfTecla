The Legend of Tecla

API publica del juego tactico por turnos construido en Java 17. La aplicacion comparte un unico motor entre la consola, la interfaz Swing y los escenarios generados o importados. Este documento describe las responsabilidades y los contratos publicos de cada paquete; el portal de documentacion que acompana al Javadoc contiene la explicacion funcional, los flujos principales y las recetas de extension.

Recorrido de una partida

  1. {@code OpcionesInicio} o la interfaz grafica recogen la configuracion.
  2. {@code FabricaJuego} elige un cargador y construye el mapa, los personajes y los objetos.
  3. {@code MotorPartida} interpreta cada accion y coordina reglas, turnos, aliados y finalizacion.
  4. El modelo de {@code world}, {@code characters} e {@code items} conserva el estado valido.
  5. Una implementacion de {@code Consola} comunica el resultado a texto o a Swing.

Principios de diseno

  • Un motor, varias interfaces: la GUI no duplica reglas de juego.
  • Modelo protegido: constructores y setters validan sus propios invariantes.
  • Cargadores intercambiables: mapas por defecto, grandes, TXT y JSON producen el mismo {@code Juego}.
  • Comandos componibles: el parser crea objetos comando simples, compuestos o repetidos.
  • Determinismo: las semillas fijas permiten reproducir mapas, enemigos y suministros.

Mapa de paquetes

Empiece por {@code engine} para comprender la orquestacion; continue por {@code model.world}, {@code model.characters} y {@code model.items} para las reglas de dominio; consulte {@code loader} para creacion y persistencia, {@code commands} para la entrada de usuario y {@code gui}/{@code console} para presentacion.
